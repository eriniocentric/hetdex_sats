# hetdex_sats — context for LLM assistants

This file documents the repo layout, pipeline design, key data structures, and
important gotchas for the HETDEX PDR1 satellite-streak analysis. It is written
for LLM coding assistants (Claude Code, Cursor, etc.) to auto-load as context.

See also `crossmatch/CLAUDE.md` for deep technical context on the SGP4
matching pipeline.

## Key files and their roles

### `intermediate/HETDEX_PDR1_sats.fits`
Input streak catalog, produced by `satellite_streak_spectra_by_shot.ipynb`.
**527 streaks** across **492 shots** (5 meteor shots removed upstream).
HDU structure:

| HDU | Type | Shape | Content |
|-----|------|-------|---------|
| `PRIMARY` | — | — | Metadata (NSTREAKS, NSHOTS, SITELAT, SITELONG, SITEELEV, etc.) |
| `INFO` | BinTable | 527 × 21 cols | One row per streak (scalar quantities) |
| `SPECTRA` | Image | (527, 1036) | Summed flux per streak (10⁻¹⁷ erg/s/cm²/Å, dilution-corrected) |
| `ERRORS` | Image | (527, 1036) | Propagated 1σ errors |
| `WAVE` | Image | (1036,) | Wavelength grid (3470–5540 Å, 2 Å/px) |

Key `INFO` columns: `streak_id`, `shotid`, `mjd_shot`, `exptime`,
`ra_cen_spax`, `dec_cen_spax`, `ra_start`, `dec_start`, `ra_end`, `dec_end`,
`seg_len_arcsec`, `streak_pa`, `g_mag`, `sb_mag_arcsec2`, `mean_snr`.

### `HETDEX_PDR1_satellites.fits`
Final publication catalog. Written by `crossmatch_and_make_catalog.ipynb`.
**Single file, fully self-contained.** HDU structure:

| HDU | Type | Shape | Content |
|-----|------|-------|---------|
| `PRIMARY` | — | — | Pipeline config header |
| (table) | BinTable | 527 rows × 42 cols | Publication table with MRT short column names |
| `WAVE` | Image | (1036,) | Wavelength grid |
| `SPECTRA` | Image | (527, 1036) | Streak spectra |
| `ERRORS` | Image | (527, 1036) | Propagated errors |
| `CANDIDATES` | BinTable | ~2635 rows | Top-5 match candidates per streak |

### `HETDEX_PDR1_sats_matched.fits` (gitignored, intermediate)
Written by the pipeline internally. Contains HDUs `INFO`, `MATCH`, `CANDIDATES`.
Not committed. The final catalog is read exclusively from `HETDEX_PDR1_satellites.fits`.

## Pipeline overview (`crossmatch_and_make_catalog.ipynb`)

Run from the **repo root** (not from `crossmatch/`). All paths are relative to
the repo root.

```
§1a  Imports + config
     CATALOG   = "intermediate/HETDEX_PDR1_sats.fits"
     CACHE_DIR = "crossmatch/tle_cache"
     OUT       = "HETDEX_PDR1_sats_matched.fits"   # intermediate, gitignored

§1b  TLE fetch (Space-Track gp_history, incremental, ~1.5–2 h first run)
§2   SGP4 coarse + fine pass (~15 min on 16 cores)
§3   Scoring and ranking (perp offset + PA residual + along-track time)
§3b  SatChecker validation (independent cross-check)
§4   Write HETDEX_PDR1_sats_matched.fits
§5a  id_source tagging
§5b  SatChecker merge for unmatched streaks
     SC_CSV = "crossmatch/satchecker_unmatched.csv"
     (skip guard: if file already exists the query is not re-run)
§6–§10  Diagnostics
§11  Write publication table:
     out_fits = "HETDEX_PDR1_satellites.fits"
     Also writes .txt (MRT) and .csv, then appends CANDIDATES HDU to .fits
```

**Important flags (in §1a config cell):**
- `FORCE_MATCH = False` — set True to force re-match even if output is current
- `FORCE_TRIAL = False` — set True to force re-run trial match
- `DRY_RUN = True` (§1b) — set False only to actually delete TLE files during refetch

## Publication table column names (MRT short names)

The pub table uses AAS MRT-compliant column names (≤8 characters). Key mappings
to/from the `INFO` table names:

| Pub column | INFO column | Description |
|------------|-------------|-------------|
| `ID` | `streak_id` | Global streak index (0-based) |
| `Shot` | `shotid` | HETDEX shot ID (YYYYMMDDsss) |
| `MJD` | `mjd_shot` | Shot MJD (UTC) |
| `Texp` | `exptime` | Exposure time (s) |
| `RAcen` | `ra_cen_spax` | Centroid RA (deg) |
| `DEcen` | `dec_cen_spax` | Centroid Dec (deg) |
| `RAsta` | `ra_start` | Start endpoint RA (deg) |
| `DEsta` | `dec_start` | Start endpoint Dec (deg) |
| `RAend` | `ra_end` | End endpoint RA (deg) |
| `DEend` | `dec_end` | End endpoint Dec (deg) |
| `Length` | `seg_len_arcsec` | Observed segment length (arcsec) |
| `PA` | `streak_pa` → published as `streak_pa_sph_deg` | Track position angle, E of N (deg) |
| `gmag` | `g_mag` | SDSS-g AB magnitude |
| `orbit_class` | `orbit_class` | LEO / MEO / GEO / HEO / Other |
| `g_mag_inst` | `g_mag_inst` | Instantaneous (undiluted) magnitude |
| `Rate` | `ang_rate_arcsec_s` | Angular rate (arcsec/s) |
| `IDsrc` | `id_source` | `spacetrack` or `satchecker` |

**Note:** `PA` in older code refers to `streak_pa_sph_deg` in newer versions.
The `streak_pa` column in the INFO table is already a proper spherical PA east
of north — no cos δ correction needed.

## Spectral flux units

- `intermediate/HETDEX_PDR1_sats.fits` SPECTRA HDU: 10⁻¹⁷ erg/s/cm²/Å
  (already dilution-corrected and divided by 2 Å bin width)
- Same convention in `HETDEX_PDR1_satellites.fits` SPECTRA HDU
- Raw PDR1 datacube DATA HDU: 10⁻¹⁷ erg/s/cm² **per 2 Å bin** — divide by 2 for /Å

## Site constants (HET)

```python
SITELAT  = +30.681436   # deg N
SITELONG = -104.014744  # deg E
SITEELEV = 2026.0       # m
```

`mjd_shot` is UTC and encodes the start of a 22-minute (1320 s) shot. The
`exptime` column is per-dither (366.9–728.0 s); use
`MatchConfig.exposure_span_s = 1320.0` to reconstruct the full shot window.
HETDEX flux calibration uses a fixed reference of 360 s regardless of actual
dither length.

## Important gotchas

1. **MRT column names ≠ INFO column names.** The publication table uses short
   MRT-compliant names. Code that previously read from `INFO` (long names) must
   map through the rename dict above when reading from the pub table.

2. **CANDIDATES HDU lives in the final catalog.** `HETDEX_PDR1_satellites.fits`
   has a CANDIDATES HDU appended by §11 of `crossmatch_and_make_catalog.ipynb`.
   If the assertion `"CANDIDATES" in hdu_names` fails in `crossmatch_figures.ipynb`,
   re-run `crossmatch_and_make_catalog.ipynb`.

3. **SatChecker CSV skip guard.** §5b skips the SatChecker API query if
   `crossmatch/satchecker_unmatched.csv` already exists. Delete this file to
   force a re-query.

4. **`streak_pa` is already spherical.** An earlier claim that it needed a
   cos δ correction was wrong. Verified against all 527 streaks: median
   difference from a true spherical PA is 0.000°, max 0.020°.

5. **`mjd_shot` is shot start, not midpoint.** It is the start of the 22-minute
   window. `exptime` is per-dither bookkeeping, not the full shot duration.

6. **Don't sort gallery by `mjd_shot` from the MATCH table** — that table has
   no `mjd_shot` column. Sort by `shotid` (encodes YYYYMMDD) instead.

7. **`sys.path` in notebooks.** Both `crossmatch_and_make_catalog.ipynb` and
   `crossmatch_figures.ipynb` run from the repo root and prepend
   `crossmatch/` to `sys.path` to import the pipeline modules:
   ```python
   sys.path.insert(0, os.path.join(os.path.abspath("."), "crossmatch"))
   ```

8. **Space-Track 204 responses.** `fetch_tles.st_get` treats HTTP 204 ("zero
   rows") as an empty result (not an error). A single empty night does not
   abort the batch. See `crossmatch/CLAUDE.md §Gotchas` for the full list of
   historical bugs.

9. **Close H5 files.** If using raw detection databases
   (`detect_index_hdr5.h5`, `detect_*.h5`), always call `.close()` after use.

10. **`make_final_catalog.ipynb` is a stale checkpoint artifact.** The current
    notebook is `crossmatch_and_make_catalog.ipynb` at the repo root. The old
    name may appear in `.ipynb_checkpoints/` — ignore it.

## Run order for full reproduction

```
1. satellite_streak_spectra_by_shot.ipynb
   → writes intermediate/HETDEX_PDR1_sats.fits

2. crossmatch_and_make_catalog.ipynb   (repo root, requires Space-Track account)
   → fetches TLE cache (crossmatch/tle_cache/, ~1.5 h first run)
   → writes HETDEX_PDR1_sats_matched.fits (intermediate, gitignored)
   → writes HETDEX_PDR1_satellites.fits / .txt / .csv

3. crossmatch_figures.ipynb   (repo root)
   → reads HETDEX_PDR1_satellites.fits
   → writes figures/*.png and crossmatch/trend_plots/*.png

4. satellite_streak_analysis.ipynb   (trend analysis, independent of step 2–3)

5. satellite_streak_figure.ipynb + paper_figures_combined.ipynb   (paper figures)
```
